# PhD Opportunity Index

一个用于 GitHub Pages 发布的静态网页版本，内容为近期海外博士岗位索引。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `phd-opportunity-index`。
2. 上传本文件夹中的 `index.html`、`.nojekyll` 和 `README.md` 到仓库根目录。
3. 打开仓库的 `Settings`。
4. 进入 `Pages`。
5. 在 `Build and deployment` 中选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. 保存后等待 1-2 分钟。

发布后链接通常是：

```text
https://你的GitHub用户名.github.io/phd-opportunity-index/
```

如果仓库名设置为 `你的GitHub用户名.github.io`，则主页链接会是：

```text
https://你的GitHub用户名.github.io/
```
